加碼回饋・注意事項：
活動期間: 115/7/1～115/12/31，消費日須於活動期間內，且廠商請款入帳日於116/1/15前之消費方符合回饋資格。
國內外一般消費享1%點數回饋無上限，國外實體商店消費享最高2.2%點數回饋(含國內外一般消費1%+國外實體商店加碼1.2%)無上限，回饋時非流通卡不予回饋。
國外實體商店消費定義：該筆交易請款時，消費地或商店登記之國別碼於國外(非台灣)，且須為面對面交易(包括以實體卡、Apple Pay、Google Pay、Samsung Pay於實體商店刷卡或感應支付)；網路交易、條碼支付或第三方支付恕不列入消費計算。相關交易判斷最終以中國信託銀行及國際組織系統資料為準。但如屬本行不回饋交易項目將不提供回饋。
國內外一般消費定義：國內外一般刷卡交易，不含本行不回饋交易項目。
【通路加碼】點數回饋為國內外一般消費1%+加碼回饋2%。
通路加碼1：限於列表合作指定商店並以 Pi 拍錢包或Hami Pay掃碼交易。四大超商為本行不回饋項目，點數回饋為加碼回饋3%。
通路加碼2：限以ALL ME卡刷卡、或將ALL ME卡綁定於 Pi 拍錢包、Hami Pay、Apple Pay、Google Pay及Samsung Pay支付方符合加碼回饋2%資格。
通路加碼1、2之指定商店請洽ALL ME卡產品網頁<加碼回饋>說明。
通路加碼1、2每戶加碼上限共計300點/月，正、附卡合併計算，計算週期係為每日曆月1~31日之入帳日，每月結算。例：8/1~8/31入帳之交易屬於8月回饋，全月回饋上限300點。

消費可累計ALL ME點(ALL ME卡)，點數1點相當於新臺幣1元。點數累計以消費金額*回饋%並四捨五入至整數為止。回饋舉例如下:
小E以ALL ME卡於8/8於韓國買了一套NT1,020元的衣服、8/10在韓國使用Uber叫車並刷卡NT373元，且皆於8/31前完成請款入帳，8月總計回饋26點，計算如下:
基本回饋:國外實體商店消費NT1,020元 x 2.2% +國內外一般消費NT373元 x 1% = 22.44點 + 3.73點，四捨五入後共26點。
小H以ALL ME卡於8/1在中華電信刷卡NT30,060元、8/18在PChome 24h購物消費NT499元，且商店皆於8月完成請款，8月總計回饋606點，計算如下:
基本回饋: NT30,060元 x 1% + NT499元 x 1% = 300.6點 + 4.99點，四捨五入後為301點 + 5點，共306點。
加碼回饋: NT30,060元 x 2% + NT499元 x 2% = 601.2點 + 9.98點，四捨五入後為601點 + 10點，已超過單月加碼上限，以300點計算。
小A以ALL ME卡於8/5以Hami Pay掃碼支付於OK超商刷卡NT120元、8/7在 Pi 拍錢包App掃碼支付於屈臣氏刷卡NT733元，且皆於8/31前完成請款入帳，8月總計回饋26點，計算如下:
基本回饋: NT120元 x 0%(超商為不回饋項目) + NT733元 x 1% = 0點 + 7.33點，四捨五入後共7點。
加碼回饋: NT120元 x 3% + NT733元 x 2% = 3.6點 + 14.66點，四捨五入後為4點 + 15點，合計共19點。(超商消費為不回饋項目，故列於加碼回饋且以3%計算補足)
